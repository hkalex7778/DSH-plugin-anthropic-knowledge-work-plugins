# /vendor-review — 供应商评审

> Modified from the original work by Anthropic.
> 移植自 anthropics/knowledge-work-plugins (operations 插件, Apache-2.0)，正文已中文化并适配 DeepSeek Harness 工具。

用结构化分析评估供应商，覆盖成本、风险、表现与匹配度。

## 我需要你提供

信息不全时先用 `ask_user_question` 一次问清：

- **供应商名称**：在评估谁？
- **背景**：新供应商评估、续约决策，还是对比？
- **材料**：合同条款、报价、方案文档，或当前表现数据。

## 评估框架

### 成本分析（总拥有成本 TCO）
- 总拥有成本（不只是许可费）
- 实施与迁移成本
- 培训与上手成本
- 持续支持与维护
- 退出成本（数据迁移、合同终止）

### 风险评估
- 供应商财务稳定性
- 安全与合规姿态
- 集中度风险（单一供应商依赖）
- 合同锁定与退出条款
- 业务连续性与灾备

### 表现指标
- SLA 达成率
- 支持响应时间
- 在线率与可靠性
- 功能交付节奏
- 客户满意度

### 对比矩阵
对比多个供应商时，产出一张并排矩阵，覆盖：报价、功能、集成、安全、支持、合同条款、参考客户。

## 连接器（可选）

若已连接**知识库**（如 Notion / Confluence）：可检索现有供应商评审、合同与表现回顾，拉取采购制度与审批阈值。

若已连接**采购系统**：可拉取当前合同条款、支出历史与续约日期，把报价与现有供应商协议对比。

以上均为**可选**：此步需在 设置 → MCP 连接对应服务；**未连接时改为手动提供内容/粘贴数据**——你直接把合同、报价单上传或粘贴，本技能照常完成评审分析。

## 提示

1. **把方案文档上传** —— 我能从供应商文档里抽出报价、条款与 SLA。
2. **做对比** —— 「供应商 A 对比供应商 B」能得到一张并排分析。
3. **带上当前支出** —— 续约时知道现在花多少，有助于评估涨价是否合理。
